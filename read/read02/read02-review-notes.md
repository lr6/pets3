# PETS3 英语知识补漏笔记

> 基于真题：2025年9月 PETS3 真题，Reading Part A, Text 2
> 只记录通用英语知识，不记录文章理解题和答案分析。

## 1. 词汇

### 高频必备

- merely 仅仅、只是；certain 某些、某个；beneath 在……下面；locate 定位、寻找
- lie 位于、坐落；gather 收集、采集；surface 表面；trunk 树干
- instrument 仪器、工具；study 研究；learn 得知、弄清楚；suggest 提出、给出
- seeds 种子；forest 森林；burn 烧；ashes 灰烬

### 语境认读

- hill 小山、山丘；hilly 多丘陵的、起伏的；wasteland 荒地、荒原；bushes 灌木丛
- mineral 矿物；metal 金属；mine 矿；ore 矿石；uranium 铀
- trained eyes 训练有素的眼光；special power 特殊能力

### 拼写或词义提醒

- minerals 不是 minierals；是“矿物”，metal 才是“金属”
- certain 不是“确定的”；learn、study 在这里都不是“学习”
- hilly 是形容词不是名词；trunk 是树干不是 root；lie 在这里是“位于”

## 2. 词义辨析

- `certain` 某些 ↔ `sure` 确定的；`study` 研究 ↔ 学习
- `learn` 学习（接语言、技能）↔ 得知（接 that / whether 从句）
- `lie` 位于 ↔ 躺；`show` 表明、显示 ↔ 展示；`high` 高 ↔ `long` 长
- `probable` 很可能 ↔ `possible` 有可能
- `mineral` 矿物 ↔ `metal` 金属 ↔ `mine` 矿 ↔ `ore` 矿石

## 3. 常用短语

- put A to use：把 A 投入使用；search for：寻找
- be based on：基于；be filled with：被……装满
- look down at：俯视、低头看；one of the + 最高级 + 复数名词：……之一
- an hour's flight：一小时的飞行（时间词加 `'s` 表时长）

## 4. 构词法

| 基础词 | 派生词 | 规律 |
|---|---|---|
| hill | hilly | `-y` 构成形容词：多……的 |
| waste | wasteland | 复合名词：荒芜 + 土地 |
| new | newest | `-est` 构成最高级 |
| locate | locating | `-ing` 动名词，跟在介词后面 |
| dig | dug | 不规则动词，过去式与过去分词同形 |
| burn | burned | `-ed` 过去分词，用于被动 |

## 5. 长句拆解

| 结构 | 识别方法 |
|---|---|
| 括弧法找主句 | 先把 `that / which / who` 引出的从句括起来，剩下的才是主句；主句必须有谓语。 |
| 插入语、同位语 | 两个逗号之间的成分先括掉：`At Watson Bar Greek, a brook..., a group gathered...` |
| 并列三项 | `A, B and C`，`and` 前的逗号表示列举未完，要一直数到 `and`。 |
| 并列被动 | 两个被动共用一个助动词：`were dug and put` 等于 `were dug and were put`。 |
| 比较方向 | 由比较词决定：`more / larger than` 前者多，`less / fewer / smaller than` 前者少。 |
| there be | `there` 是引导词，真正的主语是 `be` 后面的名词，单复数看它。 |
| A of B | 中心词是 A，`of B` 只修饰 A。 |
| each + 单数谓语 | `Each bag and box was marked.` 对比 `The bags and boxes were marked.` |

## 6. 代词和指代

代词不一定只指最近的名词。把候选代回原句试读，看是否通顺；还要看它后面跟的修饰语，修饰语会限定它只能是什么。名词短语也会回指。

常见回指词：`it`、`they`、`them`、`those`、`this`、`which`、`accordingly`。
