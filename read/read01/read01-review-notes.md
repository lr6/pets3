# PETS3 英语知识补漏笔记

> 基于真题：2025年9月 PETS3 真题，Reading Part A, Text 1

## 1. 词汇

### 高频必备

- continuously 持续不断地；merely 仅仅、只是；worldwide 全世界的、广泛地；clue 线索
- superstition 迷信；interpretation 解释、解读；indication 迹象、表明；spirit 精神、心灵
- accordingly 据此、按照前面提到的内容；universal 普遍的、共同的；unreasonable 不合理的；vocational 职业的
- reassurance 安慰、打消疑虑；remarkable 非凡的、奇妙的；mechanism 机制；conscious 有意识的
- clever 聪明的、巧妙的；get rid of 清除、摆脱；be possessed of 被……控制、附身；equivalent 对应说法、等同表达

拼写或词义提醒：

- spirit，不是 sprit
- worldwide，不是 worldside
- vocational，不是 vacation
- reassurance 是“安慰、打消疑虑”，不是“安稳”

### 语境认读

- Virginia 弗吉尼亚州；clothes pin 衣夹；stand on one's head 倒立；do any good 起作用、有效果
- curiously enough 说来奇怪；heartily 衷心地、完全地；scholastic 学校的、学业的；tuberculosis 肺结核
- ex-sneezer 不再打喷嚏的人；strangely 奇怪的是；dust 灰尘

## 2. 词义辨析

- `subject`（一词多义）：话题、主题、现象；学科、科目。具体意思看上下文。
- `mentally ill` 患有精神疾病；`heavy mental burden` 沉重的心理负担。
- `vacation` 假期；`vocation` 职业；`vocational` 职业的。
- `nature` 大自然、自然；`human nature` 人的天性、人性。

## 3. 常用短语

- stand on one's head：倒立
- nothing did any good：完全没有效果
- according to：根据……；表示信息来源
- trace back to：追溯到……；表示历史来源
- still continue：仍然延续；表示现在仍在继续
- get rid of：清除、摆脱
- be possessed of：被……控制、附身

## 4. 构词法

| 基础词 | 派生词 | 规律 |
|---|---|---|
| continue | continuous → continuously | 继续 → 持续的 → 持续不断地 |
| sneeze | sneezer | `-er` 表示“做某事的人” |
| science | scientist | `-ist` 表示“人” |
| psychology | psychological | `-ical` 构成形容词 |
| indicate | indication | `-tion` 构成名词 |
| reassure | reassurance | `-ance` 构成名词 |
| adjust | adjustment | `-ment` 构成名词 |
| vocation | vocational | `-al` 构成形容词 |
| reason | unreasonable | `un- + reasonable` |
| possess | possessed | 被控制的、被附身的 |

记忆步骤：找词根 → 看后缀词性 → 结合上下文验证，不随意删字母。

## 5. 长句拆解

顺序：找谓语 → 找主语和宾语 → 去掉介词短语 → 找并列成分 → 找 that / which 从句 → 判断代词。

| 结构 | 识别方法 |
|---|---|
| 被动语态 | `The clue for the treatment was found in a book.` 先抓 `The clue was found in a book`；`for...`、`in...` 是介词短语。 |
| 插入语 + 同位语 + which | `X, he said, a view which other people would have agreed with.` `he said` 是插入语；`a view` 指前文观点；`which` 指 `a view`。 |
| 并列成分 + 介词短语 | `[A], [B], and [C] + 谓语 + 宾语。` 先找谓语，再找并列成分，最后处理介词短语。 |
| 连续两个 that 从句 | `the belief that A was an indication that B was troubled`；第一层 that 引出 belief 的内容，第二层 that 引出 indication 的内容。 |

## 6. 代词和指代

代词不一定只指最近的名词，也可能指前文的一个问题、整件事、观点或句子。判断方法是把可能的指代对象代回句中，看意思是否通顺。

`accordingly` 也是回指词，相当于 `according to that`，表示“按照前面提到的内容”。
